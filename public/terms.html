What A11yLens is

A11yLens is a free, open-source (MIT licensed) tool that scans a website you provide for accessibility (WCAG) and performance issues using axe-core, and uses Google's Gemini API to generate plain-language explanations of the findings. It is provided as-is, described further in the project README.
