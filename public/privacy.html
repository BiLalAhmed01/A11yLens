What we don't collect

  • No accounts, sign-ups, or passwords.
  • No cookies are set by this site.
  • No analytics, tracking pixels, or advertising scripts of any kind.
  • No payment information — the tool is free.

Third-party requests made by these pages

Every page on this site loads web fonts from Google Fonts (fonts.googleapis.com and fonts.gstatic.com). Loading a font this way sends your IP address and browser information to Google as part of that request, independent of anything this site does. See Google's Privacy Policy for how Google handles that.

What happens when you use the scan feature

The dashboard's scan feature only works when connected to a running A11yLens server (see the project's README for when that's the case for this deployment). When it is running and you submit a URL to scan:

  • The URL you type is used to crawl the website you specify — not this site, not you personally.
  • Content scraped from that target website (page structure, small HTML snippets flagged by accessibility checks) is sent to Google's Gemini API so it can generate plain-language explanations. That is data about the site you chose to scan, processed by Google under Google's Gemini API terms.
  • The scan result is returned directly to your browser in the same request. The server does not write scan results to a database or persistent log — only progress and error messages appear transiently in the server's own console output, which is not collected, transmitted, or stored by us beyond that.

If you run the command-line tool yourself instead of the dashboard, generated reports are written to a reports/ folder on your own machine and never leave it unless you send them somewhere yourself.

Only scan websites you own or have explicit permission to test. See the Terms of Service for why.

Data retention

We don't hold any persistent store of scan URLs, scan results, or visitor data. There is nothing on our side to retain beyond the lifetime of a single request.

Children's privacy

This site is not directed at children, and we don't knowingly collect data from children.
